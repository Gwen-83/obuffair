✨ Bonnes Pratiques & Directives

📋 Utilisation des couleurs

  • Bleu primaire (#002A5C): Actions principales, navigation, headers
  • Jaune/Or (#FFC72C): Appels à l'action importants, éléments premium
  • Vert (#2E7D32): Validations, confirmations positives
  • Rouge (#C62828): Erreurs, actions destructrices uniquement
  • Orange (#F57C00): Avertissements, attention requise
  • Gris (#757575): Texte secondaire, éléments inactifs

♿ Accessibilité

  • Contraste minimum 4.5:1 pour le texte normal, 3:1 pour le texte large
  • Utiliser les balises sémantiques (<button>, <label>, <nav>)
  • Ajouter aria-label pour les boutons sans texte visible
  • Testable au clavier (Tab, Enter, Escape)
  • Icônes accompagnées de texte ou d'une description
  • Respecter l'ordre logique de la tabulation

⚡ Performance

  • Utiliser le CDN pour Bulma et Font Awesome (déjà intégrés)
  • Minifier le CSS et JS en production
  • Optimiser les images: format (WebP), compression, tailles appropriées
  • Lazy-loading pour les images non-critiques
  • Éviter les animations excessives

📱 Mobile First

  • Concevoir d'abord pour mobile, puis adapter aux plus grands écrans
  • Utiliser les classes responsive de Bulma: is-full-mobile, is-half-tablet, etc.
  • Menu mobile avec toggle (hamburger menu)
  • Touch-friendly: zones cliquables d'au moins 44x44px
  • Éviter le débordement horizontal

🎯 Conventions de nommage

  • Préférer les classes Bulma autant que possible
  • Préfixer les classes custom: .flight-card, .booking-form
  • Éviter les styles inline (utiliser des classes CSS)
  • Utiliser des variables CSS pour les valeurs répétées
  • BEM ou conventions similaires pour les modifications

🔗 Compatibilité navigateurs

  • Chrome/Chromium (latest)
  • Firefox (latest)
  • Safari (latest)
  • Edge (latest)
  • Mobile: iOS Safari 12+, Chrome Mobile
